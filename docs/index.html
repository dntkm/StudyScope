02计划

粗粒度的问题地图 · 随讨论修订

这些是想探索的问题，不是已学会的清单。状态来自学习观察，不以刷题次数或分数判断。

01待探索

模型表达与架构

模型能表示什么，结构为什么会影响方案选择。

想弄懂的问题
  • 非线性为什么能改变表达能力？XOR 到底说明什么？
  • 表达得出来，为什么仍然可能学不到或泛化不好？
  • 特征与表示怎么选？CNN 与 Transformer 的结构选择依据是什么？
  • Attention 在做什么？next-token 训练产生哪些能力，又有哪些局限？
02待探索

学习机制

数据、损失、概率与优化如何共同决定学到的结果。

想弄懂的问题
  • 平方损失和绝对损失分别在偏好什么结果？
  • 噪声假设与最大似然有什么关系？不同错误代价怎么进入目标？
  • 梯度的局部信息如何用于优化？反向传播是什么、解决什么问题？
  • 模型大小、数据量与正则化如何相互影响？
03待探索

现实问题建模

先把现实需求变成可验证的输入、输出和目标。

想弄懂的问题
  • 任务的输入、输出、目标和成功标准应该怎样设计？
  • 标签有噪声或存在多个合理答案时，训练目标怎样选？
  • 什么时候用预训练、微调或从头训练？
  • 参数、数据与计算预算应该怎样分配和取舍？
04待探索

评估诊断与泛化 / 置信度

判断效果是否可信，定位问题，再决定下一次实验。

想弄懂的问题
  • 验证集在验证什么？数据泄漏如何让结果失真？
  • 如何区分数据、表达能力、优化和泛化问题？
  • 训练故障该怎么诊断，什么小实验能排除一个解释？
  • 概率校准意味着什么？置信度如何用于安全决策？
