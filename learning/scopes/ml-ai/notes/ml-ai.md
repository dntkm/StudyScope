# 机器学习 / AI Agent · 领域概述

机器学习利用数据学习可复用的关系，用于预测、分类、生成或辅助决策。神经网络是其中一类模型；本领域关注怎样理解并判断 ML 方案，并逐步连接到 AI Agent 系统的设计与评估。

## 学习目标

能够解释模型能表示什么、怎样学习、任务应如何定义，以及效果是否可信。实现可以由 AI 协助；学习重点是机制、关键公式的含义、条件与权衡，以及能够验证判断的小实验。

## 本领域的路线

先在 Stage 1 建立模型结构、训练机制、典型架构、任务建模和评估诊断的基础，再依据届时官方资料进入同一 Scope 下的 CS329Z 阶段。CS329Z 是长期方向，CS336 不作为必修前置；数学随具体问题补充。具体计划与进度以 `path.json` 为准，学习偏好见 `profile.md`。

- [Stanford CS329Z](https://cs329z.stanford.edu/)：AI Agent 工程的方向锚点，后续按具体问题读取官方材料。
