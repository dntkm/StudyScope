# 机器学习 / AI Agent · 领域画像

本领域目标是理解并判断 ML 方案：实现可以由 AI 协助，学习者能够判断方案是否合理、假设是什么、如何验证。本领域长期方向目标是 Stanford CS329Z。CS336 不是必修前置。以下起点和学习偏好仅用于这个领域，不自动适用于其他领域。

## 已确认的起点

- 有丰富的软件与多语言工程经验；不重学 Python 基础。
- 大学数学遗忘较多，遇到具体问题时补基础。
- 向量与矩阵乘法、维度、复合函数和链式法则都曾学过，仍有印象；不单设系统数学补习，按具体问题复习。
- 用过 PyTorch 后训练，不以 API 练习为学习目标。
- 希望理解反向传播的概念与作用，不默认要求逐层手算梯度。
- 学习深度包括：解释机制与假设、关键公式的意义、方案权衡、预测改变条件的影响，以及设计验证实验。可以按问题需要使用数学与推导。

## 当前教学起点与待补知识

2026-10-26 根据首次教学讨论修订。以下是可修订的教学起点，不是 Topic 掌握认证；问题地图中的话题也不表示已经学会。

- 线性代数与仿射模型有可用基础：学习者能将两个输入、三个单元对应为二维到三维映射，并主动指出追加常数 1 可将偏置并入权重矩阵。熟悉的矩阵与梯度基础可快速经过。
- 梯度方向已有基础：讨论中能判断更新方向与梯度夹角小于或大于 90 度时的一阶损失变化。垂直方向的一阶变化与有限步长的区别、小学习率与有限训练步数的关系已澄清，尚待后续应用中观察。
- 已围绕固定预测例子讨论绝对损失、平方损失、偏离值和不对称错误代价。学习者自述对预测倾向有初步理解；具体理解证据、纠正与未解问题保留在 checkpoint 和对应的 Topic 笔记中。
- 隐藏层、激活函数与多层数据流已用具体小网络展开一轮。学习者能判断 ReLU 对正值的作用，提出用 $h_2+h_3$ 合成两数差距，并识别负温度预测与非负输出约束的冲突。XOR 与仿射层合并已讨论，尚未以新网络独立设计确认更广泛迁移。
- 已用同一小网络串起前向计算、输出层梯度和通向第一层的单条链式求导。学习者主动把输出层与线性回归联系起来，能复述从前向到反向求梯度、再更新参数的顺序；同一参数状态和批量前向的含义经追问澄清后自述理解。不默认逐层手算全网梯度。
- 已讨论普通 SGD 和动量。学习者能概括优化器使用当前梯度、历史状态和超参数决定更新的目标；是否收敛或局部最优的条件已补清。Adam、梯度消失与爆炸仍待展开。
- 学习者自述做过相关项目，对输入、标签、分类与回归、数据集划分和过拟合已有概念。后续围绕具体任务细化验证集与测试集的职责、泛化差距及其可能原因，不重复完整入门诊断。

## 如何一起学习

家教会话是学习界面；网站用于只读导航和回顾；仓库是可接续的学习档案。

每次从一个真想弄懂的问题开始：听当前理解 → 补关键缺口 → 图、公式或例子 → 换场景讨论 → 必要时小实验 → 短总结。卡住时直接解释，不无限苏格拉底式追问；不把复述或固定次数答对当作掌握。

新概念需要放慢：先解释符号和每个量的角色，再沿用同一个小网络逐步增加内容；避免在权重、中间结果和层级记号之间频繁换写法。笔记先列符号说明，再写公式与数值例子，数学书写遵循 `AGENTS.md` 的 LaTeX 约定。熟悉矩阵和梯度，不代表神经网络新概念可以同样快速跳过。

结束时整理今天解决的问题、理解证据（可修订观察）、尚未解决的问题、一个下一步和必要来源。先展示给学习者，欢迎修订；不编造课堂记录，不设置分数、打卡或自动提醒。
